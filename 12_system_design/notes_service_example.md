# Notes service — пример системного дизайна

```text
Пользователь → API → Сервис заметок → База данных
                       ↓
                 Журнал событий
```

- API принимает запросы.
- Сервис проверяет данные и выполняет правила приложения.
- База данных хранит заметки.
- Журнал событий помогает разбирать ошибки.
